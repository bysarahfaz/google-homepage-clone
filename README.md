#Google Homepage Clone

A simple recreation of Google's homepage built with HTML and CSS as a beginner web development learning project.

## Features

- Responsive homepage layout
- Search bar and button styling
- Hover effects
- Navigation links for visual representation

## Notes

- The search bar is for visual demonstration and does not perform actual searches.
- Navigation links are placeholders and do not lead to the original destinations.

## Technologies

- HTML
- CSS

## Learning Goals

- Practising HTML structure and CSS styling
- Understanding responsive layouts and hover effects
- Learning GitHub repository management and website deployment
